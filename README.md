# cure-vas English site

English version of the information site of the **research group on drug therapy for
intractable vascular tumors and vascular malformations** (AMED Ozeki Group / Sirolimus
Research Group), Department of Pediatrics, Gifu University Hospital. The Japanese original
is at <https://cure-vas.jp/>.

MICHI制作

## Structure

Static HTML site (no build step). Open `index.html` in a browser to view.

| Path | Page |
|------|------|
| `index.html` | Home |
| `about/` | About This Site |
| `diseases/` | Understanding the Diseases |
| `sirolimus/` | About Sirolimus |
| `research/` | Research Group & PPI |
| `news/` | News |
| `professionals/` | For Healthcare Professionals |
| `css/style.css` | Shared stylesheet |

## Notes

- Content is an English adaptation of the public Japanese site, written for patients,
  families, and healthcare professionals.
- All pages carry a medical disclaimer and link back to the Japanese official site.
- Approval details (e.g. the 2024 expanded sirolimus indication and granule formulation)
  are specific to Japan.
