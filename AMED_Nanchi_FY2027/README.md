# AMED 難治性疾患実用化研究事業 — 2027年度 申請準備

申請者：岐阜大学 小児科
想定テーマ領域：血管腫・血管奇形の薬物療法／遺伝子解析／基礎研究

> 「2027年度申請」が **2027年度開始課題（2026年秋〜冬公募）** か **2027年度中の公募（2028年度開始）** かは、公募要領の公開時期を見て確定すること。

## フォルダ構成

| フォルダ | 内容 |
|---|---|
| `01_公募情報/` | 公募要領・公募区分・評価基準・説明会資料、過去の採択課題一覧 |
| `02_研究開発提案書/` | 提案書ドラフト（背景・目的・計画・出口戦略・ロードマップ） |
| `03_予備データ/` | 遺伝子解析結果、臨床データ、基礎研究データ、図表 |
| `04_研究体制/` | 研究分担者・協力機関リスト、承諾書、学会・患者会との連携 |
| `05_予算/` | 年度別予算案、機器・解析費・人件費の見積 |
| `06_参考文献/` | 主要文献、ガイドライン、先行研究 |
| `07_様式_eRad/` | 指定様式、e-Rad 登録情報、エフォート管理 |
| `08_提出版/` | 最終提出ファイル（版管理） |

## 準備チェックリスト

- [ ] 公募要領を入手し、該当する公募区分・応募要件を確認
- [ ] 過去の採択課題（血管腫・血管奇形、関連疾患）を整理し差別化点を明確化
- [ ] 研究目的・出口戦略（薬事承認・適応拡大・ガイドライン反映など）を決定
- [ ] 予備データの図表化
- [ ] 研究分担者・協力機関の確定と承諾取得
- [ ] 倫理審査・臨床研究法／治験の位置づけ確認
- [ ] 予算案作成
- [ ] e-Rad 研究者番号・所属機関手続きの確認
- [ ] 学内締切（研究推進部門）の確認
- [ ] 提案書の内部レビュー
- [ ] 提出
