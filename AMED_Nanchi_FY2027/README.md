## e-Rad の注意点（入力方法資料より）

- 研究機関・研究者の e-Rad 登録や更新は **締切の2週間以上前** までに済ませる
- 締切を過ぎた提出は **一切受理されない**。締切直前はアクセスが集中する
- 代表研究機関と **全参加機関の了承** を事前に得る
- **研究インテグリティ情報の e-Rad 登録** が未完了だと応募できない（分担者を含む）
- 受付期間内に、状態が「応募中」、ステータスが「配分機関処理中 申請中」になっていることを確認する
